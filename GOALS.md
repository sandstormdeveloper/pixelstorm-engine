# Borrador TFG

## Enfoque del proyecto

Desarrollar un motor de videojuegos especializado en la creación de videojuegos 2D con
estilo pixel art, optimizado para la gestión de sprites, animaciones y físicas 2D.

## Requisitos mínimos

```
● Ventana y renderizado
● Sistema de entidades (ECS)
● Componentes (transform, collider...)
● Gestión de recursos
● Sistema de input
● Sistema de partículas
● Shaders básicos
● Físicas y colisiones
● Sistema de escenas
```

## Requisitos opcionales

```
● Editor de partículas
● Editor de niveles (muy básico)
```

## Stack elegido

```
C++ OpenGL GLAD GLFW CMake GLM ImGui
```
